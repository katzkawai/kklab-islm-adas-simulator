\section{はじめに：なぜ「非線形LM曲線」と「期待インフレ率」なのか？}
% ============================================================================

学部初級・中級レベルのマクロ経済学で学ぶ標準的なIS-LMモデルでは、財市場の均衡を表すIS曲線が右下がりの直線、貨幣市場の均衡を表すLM曲線が右上がりの直線として描かれる。そして、拡張的財政政策（政府支出 $G$ の増加）を行うと名目金利が上昇し、民間投資 $I$ が減少する「クラウディング・アウト（押出効果）」が生じる一方、金融緩和（マネーサプライ $M$ の増加）を行えば名目金利が低下して民間投資と実質GDP $Y$ が拡大すると説明される。

しかし、1990年代末から2020年代初頭にかけての約25年間の日本経済を観察すると、この「標準的な直線型IS-LMモデル」だけでは説明しがたい2つの大きなパズルが存在した。

\begin{enumerate}[label=\textbf{パズル\arabic*:},leftmargin=22mm]
  \item \textbf{ゼロ金利制約と「流動性の罠（Liquidity Trap）」}\\
  日本銀行が短期金利をほぼ $0\%$ に誘導し、2016年には日銀当座預金の一部に $-0.1\%$ の金利を適用しても、金利の追加的な引き下げ余地は限られた。マネタリーベースの拡大が、そのまま貸出や総需要の拡大につながるとは限らない。
  \item \textbf{デフレ予想による実質金利の高止まり}\\
  名目金利 $i$ がほぼ $0\%$ という超低金利であるにもかかわらず、企業の設備投資 $I$ が長らく低迷した。その背景には、物価が継続的に下落する\textbf{デフレ予想（$\pi^e < 0$）}の下で、企業が直面する\textbf{実質金利 $r = i - \pi^e$} がプラス圏で高止まりしていたことがある。
\end{enumerate}

本教材で用いるシミュレーターは、この2つのメカニズムを明示的に数理モデルへ組み込み、スライダー操作と歴史的プリセットによって直感的に理解できるよう設計されている。

\section{シミュレーターの理論モデル（数理仕様）}
% ============================================================================

シミュレーターの背後で計算されている連立方程式体系（IS曲線・非線形LM曲線・フィッシャー方程式・AD-AS曲線）を確認しておこう。

\subsection{財市場とIS曲線（フィッシャー方程式の組み込み）}

財市場の均衡条件（総生産 $Y =$ 総需要 $C + I + G$）は以下で与えられる。
\begin{align}
  Y &= C + I + G \label{eq:goods_eq} \\
  C &= C_0 + c(1 - t)Y \label{eq:consumption} \\
  I &= I_0 - b r \label{eq:investment} \\
  r &= i - \pi^e \quad \text{（フィッシャー方程式）} \label{eq:fisher}
\end{align}
ここで各変数の意味とシミュレーターでの単位は以下の通りである。
\begin{itemize}[noitemsep]
  \item $Y$: 実質GDP（兆円、潜在GDPは $Y^* = 550$ 兆円に設定）
  \item $C_0$: 基礎消費（兆円）、$c = 0.62$: 限界消費性向、$t$: 比例所得税率（式では $0.22$、スライダーでは $22\%$）
  \item $I_0$: 企業のアニマルスピリット（独立投資、兆円）、$b > 0$: 投資の金利感応度（兆円／\%ポイント、弾力性ではない）
  \item $G$: 政府支出（兆円）
  \item $i$: 名目金利（$\%$）、$\pi^e$: 期待インフレ率（$\%$）、$r$: 事前的実質金利（$\%$）
\end{itemize}

本モデルは閉鎖経済の短期比較静学であり、動学的な調整過程や貿易、政策金利ルールを含まない。プリセットは教育用の仮定値で、GDP・物価・期待などの実績を推定したものではない。$C_0 = 85$ 兆円とする。$t$ は所得への比例課税であり、消費税固有の価格への影響は表さない。$I$ は線形近似の投資需要である。極端な設定で負値となる場合は、現実の設備投資額として解釈できる範囲を外れる。

式\eqref{eq:fisher}は低い金利・インフレ率の下での近似である。厳密には、同じ期間に対して $1+r/100 = (1+i/100)/(1+\pi^e/100)$ だが、シミュレーターは一貫して $r=i-\pi^e$ を使用する。

式\eqref{eq:goods_eq}〜\eqref{eq:fisher}を整理すると、実質GDP $Y$ と名目金利 $i$ の関係を表す\textbf{IS曲線}が得られる。
\begin{equation}
  Y = \alpha \Bigl[ (C_0 + I_0 + G) - b(i - \pi^e) \Bigr], \qquad
  \text{ただし乗数 } \alpha \equiv \frac{1}{1 - c(1 - t)}
  \label{eq:IS_Y}
\end{equation}
縦軸に名目金利 $i$ をとる逆関数形で書けば、IS曲線は次のようになる。
\begin{equation}
  i_{\mathrm{IS}}(Y) = \pi^e + \frac{(C_0 + I_0 + G) - Y / \alpha}{b}
  \label{eq:IS_i}
\end{equation}

\begin{theorybox}{デフレ予想（$\pi^e < 0$）がIS曲線に与える影響}
式\eqref{eq:IS_i}から明らかなように、期待インフレ率 $\pi^e$ が低下してマイナス（デフレ予想：$\pi^e < 0$）になると、同じ名目金利 $i$ の下でも実質金利 $r = i - \pi^e$ が上昇するため、民間投資 $I = I_0 - b(i - \pi^e)$ が減少する。図の上では、\textbf{デフレ予想の深化（$\pi^e$ の低下）は名目金利空間 $(Y, i)$ におけるIS曲線を下方（左方）へシフトさせる}。
\end{theorybox}

\subsection{貨幣市場と非線形LM曲線（流動性の罠の定式化）}

現金の名目収益率はゼロだが、保管・輸送などの費用があるため、名目金利の実効下限は厳密なゼロとは限らない。本モデルでは説明用に $i_{\min} = -0.10\%$ と固定する。下限に近づくほど貨幣保有への需要が強くなる形を仮定するが、この値は全時期の政策金利や実効下限を推定したものではない。

これを表現するため、実質貨幣需要関数 $L(Y, i)$ を双曲線項を含む非線形関数として定式化する。
\begin{equation}
  m \equiv \frac{100M}{P} = L(Y, i) = k Y + \frac{h}{i - i_{\min}} - L_0 \qquad (i > i_{\min})
  \label{eq:money_demand}
\end{equation}
ここで $M$ はモデル上の名目貨幣量、$P$ は基準値 $100$ の物価指数、$m$ は基準年価格で測る実質貨幣残高である。$k = 0.58$、$h = 48$、$L_0 = 165$ とする。式\eqref{eq:money_demand}は平滑化前の基本形であり、$d \equiv m + L_0 - kY > 0$ の範囲で次を得る。
\begin{equation}
  i_{\mathrm{LM}}^{(0)}(Y, P) = i_{\min} + \frac{h}{m + L_0 - kY} = i_{\min} + \frac{h}{d}
  \label{eq:LM_i}
\end{equation}

基本形\eqref{eq:LM_i}の形状には2つの領域が存在する（図\ref{fig:islm_concept}参照）。
\begin{enumerate}
  \item \textbf{流動性の罠領域（低 $Y$ または大 $m$）}: $m + L_0 - kY$ が十分に大きいとき、右辺第2項は $0$ に近づき、$i_{\mathrm{LM}} \approx i_{\min}$ となって\textbf{LM曲線はほぼ水平}になる。
  \item \textbf{通常〜古典派領域（高 $Y$ または小 $m$）}: 経済活動 $Y$ が拡大して貨幣の取引需要 $kY$ が実質貨幣残高に迫ると、分母が小さくなり、名目金利 $i$ が急上昇して\textbf{LM曲線は急勾配（右上がり〜垂直）}となる。
\end{enumerate}

実装では $d \leq 0$ でも連続的に計算できるよう、分母を次の関数で平滑化する。
\begin{equation}
  S(d) = \frac{d + \sqrt{d^2+4s^2}}{2},\quad s=6.5,\qquad
  i_{\mathrm{LM}} = i_{\min} + \frac{48}{S(d)}.
  \label{eq:LM_smooth}
\end{equation}
$S(d)>0$ なので金利は常に下限より高く、$d \gg s$ なら基本形に近づく。ただし平滑化後は有限の $Y$ で垂直にはならない。この式に厳密に対応する貨幣需要は、$q\equiv i-i_{\min}>0$ として
\[
  m = 0.58Y + \frac{48}{q} - \frac{6.5^2}{48}q - 165
\]
である。画面の「流動性の罠」は $i-i_{\min}<0.38$ パーセントポイントという説明用の判定であり、金融政策の効果が厳密にゼロになる境界ではない。

\subsection{総需要（AD）・総供給（AS）と一般均衡}

IS式\eqref{eq:IS_i}と平滑化LM式\eqref{eq:LM_smooth}から名目金利 $i$ を消去し、各物価水準 $P$ に対応する財・貨幣市場同時均衡の産出量 $Y$ を求めたものが\textbf{総需要（AD）曲線} $Y = Y_{\mathrm{AD}}(P)$ である。物価 $P$ が上昇すると実質貨幣残高 $m = 100M/P$ が減少してLM曲線が左上方へシフトするため、AD曲線は右下がりとなる（ただし流動性の罠の深部ではLMシフトの影響が小さいため、AD曲線の傾きは急になる）。

一方、短期の\textbf{総供給（SRAS）曲線}は、期待インフレ率 $\pi^e$、産出量ギャップ $Y - Y^*$、外生的な供給コストショック $\varepsilon_s$ に依存する、次の説明用の線形関数である。
\begin{equation}
  P_{\mathrm{AS}}(Y) = 100 + 1.8(\pi^e + \varepsilon_s) + 0.08(Y - 550)
  \label{eq:AS}
\end{equation}
$\pi^e$ は百分率の表示値（例：$1.2$）、$\varepsilon_s$ はモデル単位であり、係数 $1.8$ はそれらを物価指数の変化へ換算する。これは期待物価水準を別途推定した式でも、インフレ率そのものの式でもない。均衡は $P=P_{\mathrm{AS}}(Y)$ をLMへ代入してISとの交点を求める。各状態のIS-LM図は、その状態の均衡物価で描かれるため、$G$ の変更でも物価経由でLMが動く。潜在GDPの縦線は参考であり、そこへの長期調整は計算しない。

また、モデルの $M$ を日銀のマネタリーベースや実際のマネーストックと同一視してはいけない。両統計は発行主体・保有主体が異なる\footnote{日本銀行「マネタリーベースの解説」：\url{https://www.boj.or.jp/statistics/outline/exp/exbase.htm}}。本モデルでは、中央銀行の資産購入から貨幣量や期待への伝達は外生的に与える。

    \item 上段の\textbf{「日本の歴史的局面プリセット」}（①1990年代末〜、②2013年〜、③2022年〜）をワンクリックすると、それぞれの時代を特徴づけるパラメータ設定が即座に読み込まれ、固定された比較基準を破線 $E_0$ として表示する。①は標準設定、②は①、③は②が基準であり、クリック順序には依存しない。

  \end{itemize}

  \end{itemize}

  \item \textbf{右ペイン中段・下段：Plotlyによる2段インタラクティブ・グラフ}
  \begin{itemize}[leftmargin=5mm,noitemsep]

  \end{itemize}

% ----------------------------------------------------------------------------
\subsection{局面① 1990年代末〜：デフレと流動性の罠（\texorpdfstring{$\pi^e < 0$}{πe < 0}, 金利下限）}
% ----------------------------------------------------------------------------

バブル崩壊後のバランスシート調整や金融システム不安を経て、1990年代末の日本経済は慢性的な総需要不足とデフレに陥った。日本銀行は1999年にゼロ金利政策を導入したが、その後も低金利とデフレからの脱却が課題となった。

\begin{simbox}{演習1：流動性の罠における金融政策の限界と財政政策の有効性}
\begin{enumerate}[leftmargin=6mm]
  \item 左ペインのプリセット\textbf{「① 1990年代末〜：デフレと流動性の罠」}をクリックする（前掲の図\ref{fig:sim_overview}の状態）。
  \item 上段のIS-LM図を観察せよ。均衡点 $E_1$ では名目金利 $i$ が約 $0.11\%$ と下限近くに張り付いている一方、期待インフレ率が $\pi^e = -1.5\%$（デフレ予想）であるため、黄色のひし形マーカーで示される\textbf{実質金利 $r = i - \pi^e$ は $+1.61\%$ と高止まり}していることを確認する（$Y = 475.0$ 兆円、GDPギャップは $-75.0$ 兆円）。
  \item 画面右上の\textbf{「現在値を比較基準(破線)に固定」}ボタンを押す。
  \item \textbf{【実験A：マネーサプライ $M$ の拡大】} マネーサプライ $M$ のスライダーを $310$ 兆円から $450$ 兆円まで右へ動かしてみよ。LM曲線は右へシフトするが、IS曲線と交差しているのはLM曲線の「水平に近い領域」であるため、名目金利 $i$ はほとんど下がらず、実質GDP $Y$ もわずか数兆円しか増加しないことを確認せよ。
  \item 一度プリセット①に戻して基準を固定し直し、今度は\textbf{【実験B：政府支出 $G$ の拡大】} 政府支出 $G$ を $104$ 兆円から $140$ 兆円へ引き上げてみよ。IS曲線が右へシフトしても名目金利 $i$ がほとんど上昇しないため、実質GDPは $475.0 \to 542.6$ 兆円と大きく拡大する一方、\textbf{民間投資は $56.3 \to 55.2$ 兆円と小幅に減少する}。金利上昇と物価上昇を無視した完全乗数 $\alpha \Delta G \simeq 69.7$ 兆円より、実際のGDP増加 $67.6$ 兆円は小さいことを確認せよ。
\end{enumerate}
\end{simbox}

\begin{theorybox}{流動性の罠近傍でクラウディング・アウトが小さい理由}
通常の右上がりのLM領域では、政府支出 $G$ の増加による所得 $Y$ の拡大が取引貨幣需要 $kY$ を増やし、貨幣市場の逼迫を通じて名目金利 $i$ を上昇させる（これが民間投資 $I$ を押し出すクラウディング・アウトの原因である）。LMがほぼ水平な領域では、所得増加による金利上昇と投資の減少は小さい。ただし、このモデルのLMは厳密には右上がりで、さらにSRASに沿った物価上昇も実質貨幣残高を減らすため、乗数効果は完全ではない。$\alpha$ がそのまま成立するのは、名目金利と物価を一定に保てる極限的な場合である。
\end{theorybox}

% ----------------------------------------------------------------------------
\subsection{局面② 2013年〜：異次元金融緩和（\texorpdfstring{$M$}{M} の大幅増と \texorpdfstring{$\pi^e$}{πe} の引き上げ試行）}
% ----------------------------------------------------------------------------

日本銀行は2013年1月に $2\%$ の「物価安定の目標」を定め、同年4月に黒田東彦総裁のもとで「量的・質的金融緩和（QQE）」を導入した\footnote{日本銀行「量的・質的金融緩和」（2013年4月12日）：\url{https://www.boj.or.jp/about/press/koen_2013/ko130412a.htm}}。QQEはアベノミクスの「第一の矢（大胆な金融政策）」に当たる。本プリセットの政府支出増は、別途「第二の矢（機動的な財政政策）」を模式化している。

\begin{simbox}{演習2：「量（$M$）」と「期待（$\pi^e$）」の役割分解}
\begin{enumerate}[leftmargin=6mm]
  \item プリセット\textbf{「② 2013年〜：異次元金融緩和（アベノミクス）」}をクリックする（図\ref{fig:sim_2013}）。このプリセットでは、比較基準（破線 $E_0$）に1990年代末のデフレ均衡が自動的にセットされ、そこからの変化が表示される。
  \item 実質GDP $Y$ が大きく回復（$475.0 \to 620.4$ 兆円）し、実質金利が $r = -1.08\%$ へ低下して民間投資 $I$ が大きく増加（$56.3 \to 113.4$ 兆円）していることを確認せよ。なぜ演習1の実験Aでは金融緩和の効果が小さかったのに、この比較では回復が大きいのか？（$M$ だけでなく、$G$・$I_0$・期待も変わっている点に注意。）
  \item 期待の寄与を他の設定変更から分けて調べるため、\textbf{期待インフレ率 $\pi^e$ のスライダーだけを $+1.2\%$ から $-1.5\%$（デフレ予想）へ戻してみよ}。たとえモデルの貨幣量 $M = 450$ 兆円・政府支出 $G = 122$ 兆円のままであっても、$\pi^e$ がマイナスのままだと実質金利 $r$ が跳ね上がり、民間投資 $I$ と実質GDP $Y$ が大きく落ち込むことがわかる。
\end{enumerate}
\end{simbox}

\begin{figure}[htbp]
  \centering
  \fbox{\includegraphics[width=0.96\linewidth]{images/sim_preset_2013.png}}
  \caption{局面②「2013年〜：異次元金融緩和」のシミュレーション画面（期待インフレ率 $\pi^e$ のプラス化により実質金利 $r$ がマイナス圏へ低下し、IS曲線が右上方へシフト）}
  \label{fig:sim_2013}
\end{figure}

\begin{theorybox}{リフレ政策（期待に働きかける金融政策）の伝達経路}
名目金利 $i$ が下限 $i_{\min}$ に制約されてこれ以上下げられない局面でも、中央銀行が将来のインフレ目標に強くコミットして人々の\textbf{期待インフレ率 $\pi^e$ を引き上げる}ことができれば、フィッシャー方程式
\[
  \Delta r = \underbrace{\Delta i}_{\approx 0} - \Delta \pi^e < 0
\]
を通じて\textbf{実質金利 $r$ をマイナス圏まで引き下げる}ことができる。これにより民間投資 $I(r)$ が刺激され、IS曲線が右上方へシフトする。一方で、スライダー $b$ や $I_0$ を動かして投資反応の違いを比較できる。ただし期待形成の過程は内生化しておらず、実際に期待インフレ率がどう変化したかや、その因果関係を本モデルだけで検証することはできない。
\end{theorybox}

\subsection{局面③ 2022年〜：コストプッシュとインフレ転換（ASシフトと \texorpdfstring{$\pi^e > 0$}{πe > 0}）}
% ----------------------------------------------------------------------------

2022年以降、ウクライナ情勢等に伴う国際資源・エネルギー価格の高騰と急速な円安進行により、日本経済は強い輸入コストプッシュ・ショック（$\varepsilon_s > 0$）に直面した。これを契機に物価上昇率が $2\%$ を超えて推移し、企業の価格設定行動や賃上げ期待にも変化が生じ、その後、日本銀行は2024年3月にマイナス金利政策の終了を決定した\footnote{日本銀行「金融政策の枠組みの見直しについて」（2024年3月19日）：\url{https://www.boj.or.jp/mopo/mpmdeci/state_2024/k240319a.htm}}。本プリセットは2022年以降を模式化したもので、2022年時点の政策金利や実績値を再現するものではない。

\begin{simbox}{演習3：コストプッシュ・インフレと「金利のある世界」への離陸}
\begin{enumerate}[leftmargin=6mm]
  \item プリセット\textbf{「③ 2022年〜：コストプッシュとインフレ転換」}をクリックする（図\ref{fig:sim_2022}）。
  \item 下段左の\textbf{AD-AS図}に注目せよ。供給コストショック（$\varepsilon_s = +2.4$、モデル単位）と期待インフレ率の上昇（$\pi^e = +2.2\%$）によって、緑色の\textbf{AS曲線がシフト前（破線）から大きく上方へシフト}し、均衡物価水準 $P$ が $117.3$ へと上昇していることを確認する。
  \item 次に上段の\textbf{IS-LM図}を見よ。この比較では名目貨幣量も $450 \to 350$ 兆円へ減っている。この減少と物価 $P$ の上昇の両方により、\textbf{実質貨幣残高 $m = 100M/P$ が $417.5 \to 298.5$ 兆円へ減少}したことでLM曲線が左上方へシフトし、さらにIS曲線の右上方シフトと相まって、均衡点 $E_1$ がLM曲線の水平部（流動性の罠）を抜け出し、\textbf{右上がりの領域（名目金利 $i = 0.50\% > 0$）へ離陸}していることを確認せよ。
  \item この状態で政府支出 $G$ のスライダーをさらに右へ動かしてみよ。局面①（流動性の罠）のときとは異なり、名目金利 $i$ が明確に上昇し、クラウディング・アウトが生じ始めることを確認できる。
\end{enumerate}
\end{simbox}

\section{発展演習とレポート・ディスカッション課題}
% ============================================================================

本シミュレーターを用いて、以下の政策シミュレーション課題に取り組み、グラフの変化とマクロ変数（GDPギャップ・民間投資・財政赤字）の数値変化を根拠として自分の考察をまとめよ。

\begin{questionbox}{課題1：日本企業の「投資の利子非感応性（低 $b$）」仮説の検証}
日本経済において金融緩和や実質金利低下の効果が限定的であったもう一つの要因として、「少子高齢化や国内市場縮小予想のもとで、そもそも企業の設備投資が金利に対して非感応的（$b$ が小さい）であり、かつアニマルスピリット $I_0$ が低下していた」という構造要因説がある。
\begin{itemize}[leftmargin=5mm,noitemsep]
  \item プリセット②（2013年異次元緩和）を選択した状態で、「現在値を比較基準(破線)に固定」せよ。
  \item 投資の金利感応度 $b$ を $16.0$ から $6.0$ へ下げたとき、および独立投資 $I_0$ を $96$ 兆円から $75$ 兆円へ下げたとき、IS曲線の傾きと位置、および均衡GDP $Y$ はどのように変化するか？
  \item このような経済構造のもとでGDPを潜在GDPへ近づけるには（過大な正のギャップにも注意）、金融政策・財政政策・成長戦略（$I_0$ の引き上げ）をどのように組み合わせるべきか論じよ。
\end{itemize}
\end{questionbox}

\begin{questionbox}{課題2：流動性の罠近傍での増税（$t$ の引き上げ）の効果}
1997年、2014年、2019年と、日本は低金利・デフレ脱却途上の局面で段階的に消費税率を引き上げてきた。
\begin{itemize}[leftmargin=5mm,noitemsep]
  \item プリセット①または②の状態を基準（破線）として固定し、簡略化した比例所得税率スライダー $t$ を $22.0\%$ から $27.0\%$ へ引き上げてみよ。
  \item 下段右のバーチャートで「財政赤字 $(G - T)$」と「GDPギャップ $(Y - Y^*)$」の変化を読み取れ。税率 $t$ を $5$ パーセントポイント引き上げたとき、財政赤字は当初意図したほど縮小するか？（ヒント：課税ベースである実質GDP $Y$ の縮小による税収 $T = tY$ の目減り効果に注目せよ）。
\end{itemize}
\end{questionbox}

\begin{questionbox}{課題3：スタグフレーション（悪性コストプッシュ）への政策対応のジレンマ}
\begin{itemize}[leftmargin=5mm,noitemsep]
  \item 標準均衡にリセットし、「現在値を比較基準(破線)に固定」した上で、供給コストショック $\varepsilon_s$ のみを $0.0$ から $+3.5$（モデル単位） へ引き上げてみよ（純粋な負の供給ショック）。
  \item このとき物価水準 $P$ と実質GDP $Y$ はそれぞれどう変化するか（スタグフレーションの確認）。
  \item この局面で（A）物価上昇を抑えるために金融引き締め（$M$ の削減）を行った場合と、（B）景気後退を防ぐために財政出動（$G$ の拡大）を行った場合のそれぞれについて、GDPギャップと物価水準 $P$ に生じるトレードオフをシミュレーターで確かめて説明せよ。
\end{itemize}
\end{questionbox}
