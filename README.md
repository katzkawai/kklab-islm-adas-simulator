# 日本マクロ経済 IS-LM / AD-AS インタラクティブ・シミュレーター

日本のマクロ経済（デフレと流動性の罠・異次元金融緩和・コストプッシュとインフレ転換）を題材とした、単一HTML完結型の **IS-LM / AD-ASモデル・インタラクティブシミュレーター** です。

> **Note:** このサイトおよびシミュレーターは **Gemini 4 Argon** で作成されました (Created with **Gemini 4 Argon**)。

## 公開デモ (GitHub Pages)

- **URL**: https://katzkawai.org/kklab-islm-adas-simulator/ （または https://katzkawai.github.io/kklab-islm-adas-simulator/）

## モデルの仕様と教育的テーマ

1. **非線形LM曲線（流動性の罠の再現）**
   - 名目金利 $i$ の実効下限（ゼロ金利制約・マイナス金利制約 $i_{\min} = -0.10\%$）を表現するため、低金利・過剰流動性領域で水平に漸近し、高稼働領域で急勾配となる非線形LM曲線を採用しています。
   - **流動性の罠**の下でマネーサプライ ($M$) を増やしても実質GDP ($Y$) を押し上げにくい現象と、その下で**政府支出 ($G$) の増加がクラウディング・アウト（金利上昇による民間投資抑制）を起こさずに完全な乗数効果を発揮するメカニズム**を視覚化します。

2. **フィッシャー方程式と実質金利 ($r = i - \pi^e$)**
   - 民間投資関数 $I = I_0 - b(i - \pi^e)$ が実質金利 $r$ に依存する構造を組み込んでいます。
   - **デフレ予想 ($\pi^e < 0$)** が名目金利下限のもとでも実質金利 $r$ を高止まりさせ、民間投資と総需要を抑制するメカニズムを再現します。

3. **日本の歴史的局面プリセット**
   - **① 1990年代末〜：デフレと流動性の罠（$\pi^e < 0$, 金利下限）**
   - **② 2013年〜：異次元金融緩和（$M$ の大幅増と $\pi^e$ の引き上げ試行）**
   - **③ 2022年〜：コストプッシュとインフレ転換（AS曲線のシフトと $\pi^e > 0$）**

4. **操作可能なパラメータ**
   - 政府支出 ($G$)
   - 消費税・所得税率 ($t$)
   - マネーサプライ ($M$)
   - 期待インフレ率 ($\pi^e$)
   - 投資の利子弾力性 ($b$)
   - 企業のアニマルスピリット / 独立投資 ($I_0$)
   - 供給コストショック ($\varepsilon_s$)
