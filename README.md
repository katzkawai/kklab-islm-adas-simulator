# 日本マクロ経済 IS-LM / AD-AS インタラクティブ・シミュレーター

日本のマクロ経済（デフレと流動性の罠・異次元金融緩和・コストプッシュとインフレ転換）を題材とした、単一HTML完結型の **IS-LM / AD-ASモデル・インタラクティブシミュレーター** です。

> **Note:** このサイトおよびシミュレーターは **Gemini 4 Argon** で作成されました (Created with **Gemini 4 Argon**)。

## モデルの仕様と教育的テーマ

1. **非線形LM曲線（流動性の罠の再現）**
   - 名目金利 $i$ の実効下限（ゼロ金利制約・マイナス金利制約 $i_{\min} = -0.10\%$）を表現するため、低金利・過剰流動性領域で水平に漸近し、高稼働領域で急勾配となる非線形LM曲線を採用しています。
   - **流動性の罠に近い領域**で貨幣量 ($M$) の拡大が実質GDP ($Y$) を押し上げにくい現象と、**政府支出 ($G$) の増加によるクラウディング・アウト（金利上昇による民間投資抑制）が比較的小さくなるメカニズム**を視覚化します。LMの勾配と物価の上昇により、乗数効果は完全ではありません。

2. **フィッシャー方程式と実質金利 ($r = i - \pi^e$)**
   - 民間投資関数 $I = I_0 - b(i - \pi^e)$ が実質金利 $r$ に依存する構造を組み込んでいます。
   - **デフレ予想 ($\pi^e < 0$)** が名目金利下限のもとでも実質金利 $r$ を高止まりさせ、民間投資と総需要を抑制するメカニズムを再現します。

3. **日本の歴史的局面プリセット**
   - **① 1990年代末〜：デフレと流動性の罠（$\pi^e < 0$, 金利下限）**
   - **② 2013年〜：異次元金融緩和（$M$ の大幅増と $\pi^e$ の引き上げ試行）**
   - **③ 2022年〜：コストプッシュとインフレ転換（AS曲線のシフトと $\pi^e > 0$）**

4. **操作可能なパラメータ**
   - 政府支出 ($G$)
   - 比例所得税率 ($t$、消費税固有の価格効果は扱いません)
   - マネーサプライ ($M$)
   - 期待インフレ率 ($\pi^e$)
   - 投資の金利感応度 ($b$、兆円/パーセントポイント)
   - 企業のアニマルスピリット / 独立投資 ($I_0$)
   - 供給コストショック ($\varepsilon_s$)

## モデルの範囲と開発時の確認

閉鎖経済の短期比較静学モデルです。歴史的プリセットは教育用の仮定値で、実績の再現や予測ではありません。物価指数は基準100のため、実質貨幣残高は `M × 100 / P` です。`r = i − πᵉ` はフィッシャー関係の近似を使用します。

- `python3 -m http.server 8000`：ローカル配信（`http://localhost:8000/`）。CDNの読み込みにはインターネット接続が必要です。
- `node --test tests/model.test.cjs`：Node.js組み込みテストで均衡条件、政策効果の符号、スライダー設定、グラフ範囲を検証します。
- `lualatex -interaction=nonstopmode -halt-on-error textbook.tex`：日本語対応のTeX環境で教材を再生成します。参照解決のため複数回実行してください。
